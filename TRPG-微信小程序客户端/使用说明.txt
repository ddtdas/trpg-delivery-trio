TRPG 跑团玩家端 · 微信小程序客户端 —— 使用说明
================================================

一、这是什么
  本目录是「TRPG 跑团玩家端」的微信小程序客户端，直接连接主持端服务器
  （FastAPI，默认端口 9210）的 /access/*、/api/*、/ws 接口，不经过任何中转服务。
  本目录已经是完整可导入的小程序工程，无需 npm install、无需构建。
  （本包与权威项目「黑客松开发文档\trpg」的对应关系，见同目录《项目说明.txt》。）

二、导入步骤（微信开发者工具）
  1. 打开「微信开发者工具」，在首页选择「导入项目」（不是「新建项目」）。
  2. 目录：选择本目录（即解压后包含 app.json、project.config.json 的那一层，
     也就是 TRPG-微信小程序客户端/ 本身）。
  3. AppID：二选一
     · 方式 A（推荐，免注册）：保持工具读到的 touristappid，
       或在下拉里选择「无 AppID / 游客模式」。
     · 方式 B（功能最全，可真机预览）：点 AppID 右侧的「测试号」，
       工具会自动申请一个测试号并写入，无需自己注册小程序。
     两种方式都不需要你提供真实 AppID。
  4. 后端服务：选择「不使用云服务」。
  5. 点「导入」。工具会自动编译并进入模拟器，首屏是「连接设置」页。

三、填写服务端地址与 token（pages/setup 页）
  进入「连接设置」页后，按顺序填写 5 个字段：
    1) 服务器地址    例：http://192.168.1.10:9210
                     （走公网穿透时填对应的 https:// 地址）
                     注意：该字段默认是空的、不预填任何地址，必须自己填。
    2) mobile token  取值：主持端 configs/access_config.yaml 中的 ends.mobile.token
    3) 连接码        主持端给出的桌面连接码
    4) 玩家 ID       自定义，如 p1
    5) 昵称          自定义
  操作顺序建议：先填「服务器地址」→ 点「测试连接」；
  再填「连接码」→ 点「解析连接码」；最后点「加入跑团」进入「桌面」页。

四、开发阶段必须打开「不校验合法域名」（重要）
  微信开发者工具默认会拦截 http:// 以及未备案域名。
  请在小程序窗口右上角「详情」→「本地设置」中，勾选：
    [√] 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书
  勾选后即可直连 http://<主持端IP>:9210。
  （本工程的 project.config.json 中已预置 "urlCheck": false，多数情况下导入后
    该选项即已勾上；若仍报「不在以下 request 合法域名列表中」，请手工再勾一次。）

五、正式发布（上线前必做）
  开发阶段用「不校验合法域名」只是本地调试开关，正式发布不生效。
  上线前请到 微信公众平台 → 开发 → 开发管理 → 开发设置 → 服务器域名，
  把主持端的 HTTPS 域名加入：
    · request 合法域名：https://<你的主持端域名>
    · socket  合法域名：wss://<你的主持端域名>
  微信要求必须 HTTPS / WSS，不能用 IP，也不能用 http://。

六、页面说明
  · 连接设置（pages/setup）—— F1 测试连接 / F2 解析连接码 / F3 本地保存身份 / F4 加入跑团
  · 桌面（pages/table）    —— F5 回合状态 / F6 行动提交 / F7 事件流（最新 50 条）/ F10 连接状态
  · 语音（pages/voice）    —— F8 录音并上传 / F9 录音设备状态
  底部 tabBar 三页可自由切换；加入跑团后会自动跳到「桌面」页。

七、常见问题
  Q1 导入时报「app.json 未找到」或提示工程目录不对？
     → 你选错层级了。要选到直接包含 app.json 的那一层（本目录本身），
       不要再往上选父目录。详见同目录《导入前检查.txt》。
  Q2 测试连接报「不在以下 request 合法域名列表中」？
     → 按第四节勾选「不校验合法域名」。
  Q3 测试连接一直失败？
     → 检查手机/电脑与主持端是否同一网段、主持端 9210 端口是否已启动、
       地址是否写成 http://IP:9210（不要漏掉 http:// 与端口号）。
  Q4 语音录制不可用？
     → 录音需要 HTTPS/localhost 环境且有可用麦克风；模拟器里可能不支持，
       请用真机预览测试。上传响应里的 stt.status 只表示服务端任务受理状态。
  Q5 提示 token 无效 / 401？
     → mobile token 必须取主持端 configs/access_config.yaml 中 ends.mobile.token，
       不能用主持端（webapp）或录音端（recorder）的 token。
  Q6 三件套怎么配合？服务端在哪？
     → 先解压并双击 TRPG-服务端.zip 里的 start.bat，再回来填地址。
       完整配合步骤见同目录《项目说明.txt》第四节。
  Q7 README.md 里提到的 tests/、docs/、packaging/ 等路径在本包里找不到？
     → 那些路径都不在本包内。逐条对照表见同目录《项目说明.txt》第七节。

九、一键启动说明（为什么本包没有 start.bat）
  本包**刻意不提供** start.bat / 一键启动脚本，这不是缺陷，而是微信小程序的运行方式决定的：
  小程序不能像 Web 客户端那样由本地脚本拉起浏览器窗口 —— 它必须由「微信开发者工具」
  编译并载入模拟器（或真机预览）。因此本包顶层不放任何 .bat，与《项目说明.txt》
  第七节「微信小程序没有 bat 启动」的口径一致。

  正确的一键启动方式 = 「先装工具，再导入项目」：

  第 1 步 · 安装微信开发者工具（只需一次）
    官方下载：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
    选择「稳定版 Stable Build」Windows 64 位，按默认选项安装即可。
    安装后一般位于：
      C:\Program Files (x86)\Tencent\微信web开发者工具\
    若你希望以后能用命令行打开本项目，可在工具内开启：
      「设置 → 安全设置 → 服务端口」→ 打开（开启后即存在 cli.bat，可用于命令行导入）
    命令行导入示例（开启服务端口后）：
      "C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat" open --project "<本目录的绝对路径>"

  第 2 步 · 检查工具是否已安装
    在 PowerShell 中执行下面这行，输出 True 即表示已安装：
      Test-Path "C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat"
    若输出 False，请回到第 1 步安装。

  第 3 步 · 导入本项目
    打开「微信开发者工具」→ 首页选「导入项目」（不是「新建项目」）→
    目录选到**本目录本身**（即直接包含 app.json 的那一层）→
    AppID 用 touristappid / 选「测试号」→ 后端服务选「不使用云服务」→ 点「导入」。
    （详细字段与后续填写见本文第二节、第三节。）

  第 4 步 · 打开「不校验合法域名」
    工具右上角「详情」→「本地设置」→ 勾选
    「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。
    （本工程 project.config.json 已预置 "urlCheck": false，多数情况下导入后即为勾选状态。）

  一句话：本包无法用纯脚本拉起界面，请按上面 4 步操作；装好工具后导入本目录即可。
